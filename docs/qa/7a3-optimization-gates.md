# 7-A-3 측정 기반 최적화 의사결정

실기기 비교 데이터가 없을 때는 음성 인식 주기, 번역 대기열, 모델 스레드 수와 추론 옵션을 임의로 조정하지 않습니다.
현재 PR은 **최적화 효과 검증 도구**이며 속도 개선이 이루어졌다는 의미가 아닙니다.

## 측정 비교
동일 Android 기기·동일 음성 입력·동일 모델·동일 앱 상태에서 기본 버전과 변경 후보를 각각 3회 이상 측정하세요.
각 회차에서 CPU/메모리/배터리 온도 데이터를 `scripts/device_perf_probe.py`로 수집합니다.

```powershell
python scripts/device_perf_compare.py --baseline measurements/baseline-01.csv --candidate measurements/candidate-01.csv --output measurements/compare-01.json
python -m unittest scripts/test_device_perf_compare.py
```

보고서에는 CPU·PSS·배터리 온도 중앙값과 p95, 측정 시작/끝의 PSS 변화량을 포함합니다.
데이터가 빠지면 null로 표시합니다. 실행 시간 차이가 10% 이상이거나 주요 샘플이 부족하면 비교 가능 여부가 false입니다.
단일 비교 보고서가 자동으로 성능 개선을 확정하지 않습니다.

## 최적화 대상 선정 원칙
- 인식 지연의 p95 또는 생략 건수가 높고 CPU 사용률도 높으면, 증분 ASR 호출 빈도를 후보로 검토합니다. 인식 정확도 및 중복 자막 회귀가 선행되어야 합니다.
- 번역 대기열이 자주 가득 차면 번역 단계의 병목, native 스레드 경쟁, 모델 호출 시간을 먼저 분리 측정합니다. 대기열 크기만 늘리는 방법은 메모리 및 지연을 키울 수 있습니다.
- PSS가 30분 동안 계속 상승하면 정상 캐시 워밍업과 누수를 구분한 뒤 재현 가능한 할당 경로를 조사합니다.
- 배터리 온도 증가는 외부 영상 앱, 화면 밝기, 충전 등 환경 변수의 영향을 받으므로 단독 근거로 쓰지 않습니다.
- PR #34의 최근 처리 시간은 큐 대기+추론의 합이며, 영상 재생 위치부터 자막 등장까지의 시간은 별도 측정입니다.

## 출시 승인
기능 회귀 테스트, 모델 무결성, 자막 누락·중복·종료 안정성을 통과해야 합니다.
A/B 비교 후 3회 이상 반복한 중앙값·p95를 기기 성능 등급별로 보고합니다.
테스트 입력·기기 조건이 다른 비교 결과는 참고로만 표시합니다.
