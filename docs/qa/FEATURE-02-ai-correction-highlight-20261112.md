# FEATURE-02 — 2차 AI 자막 교정 및 변경 단어 강조

- 대상: `hebi10/LiveTranscribe-Android`
- 기준 main: `acc5d45cef8440c56ba9522bdfa978aa692beab5`
- 상태: 기능 구현 브랜치, 자동 CI·Android 실기기 검증 **대기**
- 기존 CAPTION FRAME의 라이트 화이트·중성 회색 / 다크 차콜·블랙 디자인 유지

## 기능 동작

1. 오프라인 음성 인식→한국어 1차 번역을 **기존 경로로 우선 출력**합니다.
2. **확정 번역문**만 대상으로 650ms 유휴 대기 뒤 기존 온디바이스 번역 모델에 자연스러운 한국어 자막 교정을 1회 요청합니다. 별도 모델 다운로드·클라우드 API 사용은 없습니다.
3. 음성 입력 이벤트가 새로 발생하면 진행 중 교정 작업은 취소합니다. 1차 번역 처리 중이거나 확정 번역 대기열이 밀렸으면 교정은 생략합니다.
4. 2차 결과가 빈 문자열, 설명형 출력, 비정상적으로 길거나 짧은 문장, 동일 문장이면 무시하고 **1차 번역을 유지**합니다. 오류·타임아웃도 1차 번역을 그대로 둡니다.
5. 같은 **세션 ID + 자막 라인 ID + 이전 번역문**이 유지된 경우에만 교정문을 반영합니다. 다른 문장을 덮어쓰지 않습니다.
6. 변경된 단어의 UTF-16 범위만 색상 강조합니다. 기본 초록 `#30C46C`, 기본 1000ms. 종료 시 기존 자막 색상 복원. 수정이 없으면 강조도 없습니다.
7. 설정: **2차 AI 교정 사용/미사용**, **교정 부분 강조 사용/미사용**, 색상 6종(초록·파랑·노랑·분홍·보라·주황), 시간 1·1.5·2초. DataStore 보존. 라이트 테마에서는 선택한 색상의 짙은 톤을 사용해 텍스트 대비를 확보합니다.
8. 분할 화면(native `CaptionReadingView`)과 팝업(`OverlayController`)은 동일한 라인 ID/강조 종료 시점을 사용합니다.
9. 동의한 번역 기록이 이미 저장되어 있고 사용자 동의 세대가 그대로라면 기존 기록 ID의 번역문만 수정합니다. 이미 삭제한 기록은 복원하지 않으며, 저장을 끈 상태에서는 새 기록을 만들지 않습니다.
10. 음성 캡처 종료 시 2차 작업 취소, 남은 강조 메타데이터 제거. 자막 읽기 스크롤 앵커 유지.

## 주의사항

- 기존 작은 로컬 번역 모델에 2차 교정 프롬프트가 실제로 얼마나 도움이 되는지는 **아직 측정하지 않았습니다**. 문법 개선 품질을 CI의 단순 UI/단위 테스트로 보증하지 않습니다.
- CI는 에뮬레이터의 테스트 UI와 정적 데이터/흐름을 확인할 뿐 실제 모델 약 2.1GB 다운로드, 음성 변환, 실기기 1·2차 번역 품질·성능을 증명하지 않습니다.
- 외부 서비스 전송, 별도 모델, 새 의존성, 강제 게시·비공개 승격을 추가하지 않습니다.
