## PR #59 의존성
- `UI-GAP-06` PR #59는 먼저 빌드·캡처·반응형 CI 성공을 확인한 후 병합한다.
- #59 병합 직후 최신 `main` SHA의 Android 기본·반응형 재캡처를 확인하고, 증거 sourceRevision과 일치시킨다.
- 기획만 작성하거나 대기 상태 PNG가 존재하는 것으로 종합 반응형 QA 완료를 주장하지 않는다.

## 추가 필수 검증
1. API 29/35/36: 화면 크기 및 권한 흐름, 시작·종료·앱 전환.
2. 라이트·다크와 시스템 모드: 표면/텍스트 대비, 터치 목표 최소 48dp, 상태·삭제 UI 색상.
3. 160% 글자 확대: CTA·설정·검색·다이얼로그 줄바꿈, 스크롤 및 잘림.
4. 분할 화면과 Overlay: 기본·확장·최소화, 드래그·리사이즈, 화면 경계, 회전과 읽던 위치 복원.
5. 기록: 저장 기본 OFF, 실제 저장/검색/개별·전체 삭제, 빈 상태·오류 상태.
6. 폴더블 실기기: 접힘·펼침 전환 및 상태/위치 보존. 실기기 증거 없으면 미검증으로 표시.
7. 모든 캡처는 소스 SHA, API, 화면 크기, 폰트 배율, 테마, 데이터 유형, SHA-256을 기록한다.

실제 AI 모델 설치·마이크/영상 음성 인식·실시간 번역 품질·발열/지연은 UI-GAP-08에서 별도 측정한다. Play 배포 및 스토어 이미지 교체는 본 QA에 포함하지 않는다.
