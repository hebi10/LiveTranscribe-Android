# READ-UX-01 — 시청 집중 모드

## 목표
영상 시청 중 자막을 읽기 쉽게 만들되 기존 사용자 설정·번역·기록을 유지합니다.

## 구현
- 신규 선택형 시청 집중 모드. 기본 OFF, DataStore 저장. 기존 사용자 동작을 자동으로 바꾸지 않음
- 최근 자막(CAPTIONS)에서는 최신 확정 번역 구간 하나만 표시. 원문은 임시 숨김이며 저장된 원문 설정값은 유지
- 집중 모드의 팝업 배경 불투명도 하한 94%로 실제 표시만 변경. 저장한 사용자 지정 투명도 유지
- 집중 모드 팝업 원문 전환 비활성화. 자막 목록(CHAT)에서는 기존 최대 40구간과 원문 계속 확인 가능
- 긴 문장 생략·자르기 없음. 기존 ScrollView·최신 자막 이동·크기·위치 보존
- 오프라인 엔진·모델·개인정보·기기 권한·서명·Play 변경 없음

## 검증
- DataStore 기본 OFF 및 설정 보존, 1구간/기존 2구간, 40구간 목록·원문 표시, 비확정 제외
- Android 단위·빌드·Lint, 팝업/분할·글자 160%·라이트/다크 및 실기기 검증
- READ-UX-00-REAL-QA 지연 실측은 별개이며 미검증 상태 유지
