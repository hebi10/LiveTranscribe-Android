# READ-UX-02 — 재생 중 집중 전환·긴 자막 가독성

## 구현
- 자막을 보고 있는 중에도 집중 모드를 변경할 수 있도록 분할 자막 설정 다이얼로그와 팝업 확장 조작부에 전환 UI 추가.
- 기존 DataStore의 동일 readingFocusMode 설정을 사용하며, 중지/재시작이나 이전 자막 삭제 없음.
- 팝업과 분할 화면에서 집중 모드일 때 Android TextView의 BALANCED 줄바꿈과 간격을 적용.
- 원문·번역문 자체는 수정하지 않음. 기존 자막 목록·오류 표시·스크롤 보존·최신 자막 복귀 기능 유지.
- 2줄은 선호 표시 목표이며 긴 번역을 강제 자르거나 타이머로 넘기지 않음.
- 팝업 포커스 조작의 최소 48dp 터치 영역·접근성 라벨·테마 반전 상태 유지.

## 검증
- 실제 API29/35/36 계측, 작은 화면·160% 글자·태블릿·가로·팝업/분할, 문장 누락/스크롤 포커스.
- 집중 토글 중 이전 위치·크기·원문 선호값·기록 보존 확인.
- Android/정적 CI 통과와 ARM64 실기기 번역 성공은 구분. 무실측 READY/PASS 금지.
- Google Play 내부/비공개/스토어 자동 업로드 없음.

## 후속
READ-UX-03: 2차 AI 교정이 시청 중 이미 읽고 있는 자막을 다시 바꾸지 않도록 사용자가 선택할 수 있는 보호 옵션 추가. 모델 처리 시간은 실기기 데이터 확보 전 튜닝하지 않음.
