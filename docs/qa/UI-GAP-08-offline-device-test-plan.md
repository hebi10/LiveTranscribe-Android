# UI-GAP-08 — 오프라인 AI 모델 실기기 기능 QA

상태: **실기기 시험 미수행 / 테스트 프로토콜 준비됨** (2026-11-11).
본 문서는 실제 기기 접속, 모델 다운로드 또는 번역 성공의 증거가 아닙니다.

## 0. 실행 전 필수 기록

- 시험 기종, Android API, ABI(ARM64), RAM, 앱 버전/커밋 SHA, 앱 설치 경로(내부 또는 debug).
- 사용 가능한 내부 저장 공간: 모델 다운로드 약 2.1GB 외 추가 작업 공간 필요. 실제 요구량은 앱 표시와 설치 결과로 확인.
- 시험용 본인 소유 또는 사용 허가된 짧은 음성/영상. 이름·대화 내용이 노출되지 않는 비식별 테스트 문장.
- Wi-Fi 연결, 배터리 잔량, 기기 초기 온도, 절전/발열 제한 상태.
- 녹음·화면 캡처·오버레이 권한은 실제 기기에서 사용자 승인 필요. 테스트 자동화를 위해 권한 우회 금지.
- 개인 음성 원본, 전체 번역문, 인증정보를 공개 GitHub Actions 로그 또는 공개 아티팩트로 업로드하지 않는다.

## 1. 판정

| 상태 | 의미 |
|---|---|
| PASS | 해당 물리 기기에서 반복 실행한 증거와 기대 동작 일치 |
| FAIL | 재현 가능한 오류; 조건·재현 단계·기기 정보 기록 |
| BLOCKED | 기기·권한·용량 등 선행조건 미충족 |
| NOT RUN | 실행하지 않음 |
| CI ONLY | 소스 단위·에뮬레이터 검사일 뿐 실기기 확인 아님 |

실기기 증거가 없으면 PASS 금지. UI 대기 화면 또는 합성 기록을 실제 음성 인식·번역 성공으로 분류 금지.

## 3. 데이터 수집 규칙

- 동일 기기, 동일 짧은 비식별 음성 샘플, 동일 입력 모드에서 **최소 3회** 반복한다.
- 시작 준비 시간, 실제 인식 완료 시점, 번역 표시 시점, 지연(ms), 누락·중복 건수, 충돌/ANR을 기록한다.
- 앱 메모리는 Android `dumpsys meminfo <패키지>`에서 PSS, CPU는 `dumpsys cpuinfo` 등에서 측정하되 Android 버전별 차이를 기록한다.
- 배터리 온도와 발열 상태는 `dumpsys battery`·`dumpsys thermalservice` 중 기기가 지원하는 출력을 사용한다. 값이 없는 경우 추정하지 않는다.
- CPU·PSS·배터리 온도의 중앙값과 지연 p95는 유효 샘플이 충분할 때만 보고한다. 샘플 수와 측정 방식을 병기한다.
- 테스트 발화의 원문·오디오·동영상 전체를 공개 로그에 남기지 않는다. 비교 정확도는 비식별 테스트 코드와 PASS/FAIL로 관리한다.

## 5. 출시 게이트 및 의존성

- UI-GAP-06 PR #59의 UI 캡처 실패: 이전 문자열 `번역 기록 저장 (기본 꺼짐)`을 찾는 테스트가 원인. 테스트 문자열 보정 커밋 반영 후 PR 재검증 필요.
- UI-GAP-07 PR #60은 반응형 누락 환경 인벤토리이며 실기기 커버리지를 제공하지 않는다.
- 모델 다운로드 100%는 READY가 아니다. 실제 SHA 검증 성공과 번역 출력이 분리된 증거로 필요하다.
- 최소 한 대의 호환 ARM64 실기기에서 DEV-01~15 결과, APK/소스 SHA, 비식별 캡처, 성능 측정 결과를 받아야 UI-GAP-08 종료 가능.
- DEV 항목에 FAIL/BLOCKED가 남으면 원인별 후속 PR을 열고 재시험한다.
- 비공개 Play 트랙 승격·스토어 성공 화면 제작·성능 개선 홍보는 실기기 검증 전 금지.
