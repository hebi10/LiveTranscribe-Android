# READ-UX-03 — 집중 시 문장 변경 방지

## 변경
- 시청 집중 모드에서 1차 한국어 번역은 기존대로 즉시 표시합니다.
- 2차 AI 교정 요청은 집중 모드 동안 생략합니다. 사용자가 이미 켜 둔 교정 선호값은 변경·삭제하지 않습니다.
- 진행 중인 보조 교정 작업은 집중 모드로 전환될 때 취소하고, 교정 완료 직전에도 설정을 재확인하여 이전 번역문을 덮지 않습니다.
- 집중 모드를 끄면 이후 새 자막부터 기존 교정 기능을 다시 사용합니다. 기존 기록·권한·모델은 보존합니다.
- 교정 사용 여부의 저장 설정, 강조 6색·1/1.5/2초 옵션은 유지됩니다.

## 회귀·QA
- 집중 OFF + 교정 ON은 기존 동작, 집중 ON + 교정 ON은 1차만, 교정 OFF는 모드에 관계없이 1차만.
- 빠른 전환, 이미 요청된 오래된 교정, 종료/취소, 기록 삭제/저장, 자막의 원문/번역문 짝 보존.
- Android 빌드/단위/Lint/API29·35·36와 ARM64 실기기 비교 필수. 서버 API·Play 업로드 없음.
- 처리 지연과 변경률은 실측을 확보하기 전까지 개선 완료로 간주하지 않습니다.
