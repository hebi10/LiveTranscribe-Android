실시간 영상 번역 개인정보처리방침

시행일: 2026년 11월 8일 · 개발자: hebi10
적용 앱: 실시간 영상 번역 (com.hebi.livetranslate) 및 별도 설치용 미리보기 (com.hebi.livetranslate.debug)

실시간 영상 번역은 Android 기기에서 음성을 인식하고 한국어 자막으로 번역하는 앱입니다. 개발자는 음성, 인식문, 번역문을 수신하는 서버를 운영하지 않습니다. 인식과 번역은 기기 안에서 수행됩니다. 다만 사용자가 모델을 다운로드하거나 이 방침을 외부 브라우저로 열면 아래에 설명한 외부 서비스와 통신합니다.

1. 음성 및 자막 처리

  • 사용자가 번역을 시작하면 선택한 마이크 음성 또는 Android가 캡처를 허용한 앱의 재생 소리를 처리합니다. 다른 앱이 오디오 캡처를 제한하면 해당 소리는 인식할 수 없습니다.
  • 음성은 메모리에서 처리하며 오디오 파일로 녹음·보관하지 않습니다. 음성, 원문 및 번역문을 외부 음성 인식·번역 API나 개발자 서버로 업로드하지 않습니다.
  • 음성 인식에는 Qwen3-ASR와 sherpa-onnx, 번역에는 Hy-MT2와 llama.cpp를 사용합니다. 언어 식별과 발화 구간 탐지도 기기 안에서 수행됩니다.
  • 화면에 표시할 최근 자막은 메모리에 보관합니다. 완료된 자막은 다음 번역 시작 또는 앱 프로세스 종료 전까지 화면에 남을 수 있습니다.

2. 번역 기록과 기기 저장

  • 번역 기록 저장은 기본으로 꺼져 있습니다. 사용자가 켠 경우 확정된 원문, 한국어 번역문, 언어, 시각 및 기록 식별자를 기기의 앱 전용 내부 영역에 저장합니다.
  • 최근 500개 기록을 보관하며 한도를 넘으면 오래된 기록부터 삭제합니다. 저장을 끄면 이후 저장을 중단하고 기존 기록은 유지합니다. 기록 화면에서 개별 삭제 또는 전체 삭제할 수 있습니다.
  • 표시 방식·글자 크기·음성 언어 등의 설정과 다운로드한 모델도 기기에 보관합니다. 번역 기록과 모델은 Android 백업 대상이 아닌 영역에 저장하며, 앱은 Android 클라우드 백업 및 기기 간 데이터 이전을 허용하지 않습니다.
  • Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 기기에 보관한 설정, 모델과 기록이 삭제됩니다. 이후 사용하려면 모델을 다시 다운로드해야 합니다.

3. 모델 다운로드와 외부 접속

사용자가 앱에서 모델 다운로드를 요청한 경우에만 대형 음성·번역 모델을 받습니다. 최초 다운로드는 약 2.12GB이며 Wi-Fi 또는 모바일 데이터를 사용할 수 있어 통신 요금이 발생할 수 있습니다. 파일은 Hugging Face의 고정된 HTTPS 주소와 HTTPS CDN을 통해 내려받으며 크기와 SHA-256을 확인합니다. 중단된 파일은 이어받기를 위해 기기에 남을 수 있습니다. 모델 준비 후 음성 인식과 번역에는 인터넷 연결이 필요하지 않습니다.

다운로드 요청에는 음성, 원문, 번역문, 계정 토큰, 쿠키 또는 앱 로그를 넣지 않습니다. 모델 제공 서버와 CDN은 통신을 처리하는 과정에서 IP 주소, 요청한 모델 경로, 접속 시각 등의 접속 정보를 볼 수 있습니다. 이 정보의 처리·보관은 해당 서비스의 정책에 따릅니다. 개발자는 해당 서버의 접속 기록을 직접 수집하거나 관리하지 않습니다. Hugging Face 개인정보처리방침을 참고해 주세요.

4. 권한

  • 마이크·오디오 녹음: 마이크 음성 및 Android 재생 오디오 캡처에 필요합니다. 권한을 거부하면 음성 인식·번역을 시작할 수 없습니다.
  • 화면 공유·미디어 프로젝션: 동영상 음성 입력을 시작할 때마다 Android의 확인을 받습니다. 앱은 재생 오디오 처리를 위해 사용하며 화면 이미지를 저장하거나 업로드하지 않습니다.
  • 다른 앱 위에 표시: 팝업 자막을 선택한 경우에 필요합니다. 분할 자막 화면에서는 이 권한 없이 사용할 수 있습니다.
  • 포그라운드 서비스·알림: 사용자가 시작한 음성 캡처와 자막 처리를 유지하고 실행 상태 및 중지 조작을 제공합니다.
  • 인터넷·네트워크 상태: 사용자가 요청한 모델 다운로드에 사용합니다. 개인정보처리방침 링크는 앱 내부 웹뷰가 아닌 외부 브라우저로 열립니다.

권한은 Android 설정에서 변경할 수 있으며 번역은 앱의 중지 조작으로 종료할 수 있습니다.

5. 계정, 광고 및 분석

앱 계정이나 로그인, 사용자 API 키 및 유료 클라우드 API가 필요하지 않습니다. 광고, 원격 이용 분석, 자동 오류 수집 및 결제 SDK를 사용하지 않습니다. 앱에서 음성·자막을 공유하거나 클립보드로 복사하는 기능은 제공하지 않습니다.
