# 일본어 음성 인식 개선

목표는 다른 앱의 일본어 영상을 보며 읽을 수 있는 한국어 자막의 원문 정확도를 개선하는 것이다. 음성·원문은 기기 안에서 처리하고, 앱에서 음성 파일이나 디버그 원문 로그를 만들지 않는다. 사용자 요청은 다른 AI 모델도 허용하며 이전 병합·APK 전달 흐름을 유지한다.

일본어는 ReazonSpeech k2-v2 int8를 기존 sherpa-onnx 1.13.8로 실행한다. 영어는 기존 Vosk를 유지한다. 일본어 인식은 16kHz mono PCM16 입력을 음성 구간으로 나누고, 독립 IO 작업이 처리한다. Silero VAD는 threshold 0.5, window 512, minSilence 1.0초, minSpeech 0.25초를 사용한다. 일본어 구간 메모리는 실제 PCM 길이로 8초를 제한하고, 디코더 끝 문맥을 위해 0.5초의 무음을 덧붙이는 효과를 공개 음성으로 검증한다. 문장 끝과 강제 경계가 일치하지 않을 수 있다.

대기 인식은 최대 2개+처리 중 1개이다. 가장 오래된 대기를 생략하면 앱과 팝업에 안내한다. 캡처 스레드에서 ASR 전체 추론을 실행하지 않는다. 일시정지는 수집 구간을 닫고, 재개 시 음성을 이전 구간과 혼합하지 않는다. 중지는 마지막 구간을 한 번만 처리하고 native 추론 완료 전 자원을 해제하지 않는다. Native CPU 추론을 강제로 끊어 해제하는 방식은 사용하지 않는다.

일본어 원문의 일본어 글자 사이 토큰 공백만 정리하며 영어·숫자·전각 문자·줄바꿈은 보존한다. 이 원문을 자막과 번역, 선택적 기록에 동일하게 사용한다. 한국어 번역은 기존 ML Kit을 유지한다. 직접 번역 후보는 크기·런타임·기기 속도 제약이 있으므로 검증되지 않은 모델을 기본 적용하지 않는다.

모델은 공식 저자 revision 291488c8151be24d7da4bf7af26e533fad96e407과 official sherpa Silero asset에서 build time에만 준비한다. 각 파일의 고정 SHA-256과 길이를 확인한 뒤 원자적으로 설치한다. 앱 네트워크·모델 다운로드 정책은 기존 ML Kit 준비 정책을 유지한다. 모델 준비 상태는 다섯 파일의 존재와 비어 있지 않음을 확인한다.

공개 일본어 음성에서 기존 Vosk와 새 모델의 문자 오류율·CPU 시간을 비교하며 실기기 수치와 구분한다. 정확도 향상을 보장하는 표현은 사용하지 않는다. 전체 단위 테스트·Python 준비/개인정보 검사·lint·APK 무결성·동일 서명을 확인하고 GitHub CI 성공 후 main에 병합한다.
