# 실시간 자막 안정화

## 목표
기존 기기 내 Qwen3-ASR·Hy-MT2 엔진과 개인정보 보호 경계를 유지하며, 연속 발화 중 안정된 문장부터 번역하고 종료·오류·화면 배율·배포의 확인된 문제를 보완한다.

## 접근
- 모델 교체는 다운로드·성능·정확도 재검증이 필요하므로 이번 범위에서 제외한다.
- 8초 상한만 줄이는 방식은 단어 경계 손실을 늘리므로 채택하지 않는다.
- 기존 최대 8초 음성 창에서 2초 간격의 누적 인식을 요청하고, 연속 가설에서 일치하는 완료 문장만 확정한다. 마지막 인식에서는 아직 확정하지 않은 나머지를 보낸다. 누적 미리보기 작업은 최신 1개로 합치며 확정 음성 대기는 기존 2개 상한을 유지한다.

## 동작
- 문장부호와 안정된 인식 접두부를 함께 사용한다. 숫자 소수점과 일반 영어 약어는 문장 경계로 오인하지 않는다. 이미 확정한 부분이 후속 가설에서 변경되면 중복 발행을 막고, 안전하게 연결할 수 없는 나머지 구간의 생략을 안내한다.
- 자동 모드 번역은 언어 식별 완료를 기다리지 않는다. 언어 표시는 별도 제한된 작업에서 보완한다. 모델 종료는 실행 중인 식별 작업이 끝난 뒤 수행한다.
- 큐는 메모리 상한을 유지하며 처리 지연 시간과 누락 횟수를 화면 상태에 제공한다. 조용한 진단은 텍스트나 음성을 로그·파일·네트워크로 내보내지 않는다.
- 중지는 캡처를 즉시 중단하고 번역 완료 대기를 요청당 15초 상한과 대기 2개에 맞춘다. 취소 불가능한 native ASR은 실행 중 메모리를 해제하지 않고, 지연된 종료임을 안내한다.
- native 시간 초과를 별도 예외로 전달한다. 팝업 배율 변경은 선호 dp와 읽던 위치를 보존한다.
- 테스트 APK는 배포 앱과 구분한다. 업데이트 APK는 기존 서명키·인증서가 제공된 보호된 수동 작업에서만 만든다. 실제 키 생성·교체, 푸시, 공개 배포는 이번 로컬 보완에 포함하지 않는다.

## 검증
문장 안정화·중복 억제·약어·일시정지·최종 꼬리·오버플로·종료·시간 초과·배율에 회귀 검사를 추가한다. 가능한 테스트를 실행하고, Android SDK나 실기기 부재로 실행하지 못한 검사는 구분해 기록한다. 모델 속도·정확도 향상은 실기기 측정 전 단정하지 않는다.
