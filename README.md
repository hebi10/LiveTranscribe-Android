# 실시간 영상 번역 (개인용)

LiveCaptionN의 MIT 라이선스 소스코드를 기반으로 한 **한국어 개인용 오프라인 영상 자막 앱**입니다. 현재 버전은 1.1.0입니다.

## 현재 엔진
- **음성 인식:** Qwen3-ASR 0.6B int8 + Silero VAD, sherpa-onnx 1.13.8. 앱에서는 영어·일본어를 선택합니다.
- **한국어 번역:** Hy-MT2 1.8B Q4_K_M + llama.cpp CPU. 영어 중간 번역 없이 한국어 결과를 생성합니다. ML Kit과 Vosk SDK는 제거했습니다.
- **언어 추천:** 독립 Whisper Tiny 모델로 다른 발화 구간에서 2회 연속 선택 언어와 다르게 인식되면 언어 변경을 제안합니다. 자동 변경·자동 재시작은 하지 않습니다.
- Android 10 이상, arm64-v8a 기기용입니다. 시스템 음성 캡처를 허용한 앱 또는 마이크를 입력으로 사용합니다.

## 최초 모델 준비
음성 인식·번역 모델은 합계 약 **2.12GB**이며 APK에 포함하지 않습니다. 앱의 **모델 준비**를 직접 눌러 Wi-Fi 또는 모바일 데이터로 받습니다. 모바일 데이터 요금과 충분한 여유 저장 공간을 확인하세요. 준비 중에는 앱을 열어 두는 것이 좋습니다.

진행률을 확인하거나 중단할 수 있으며, 다시 준비하면 중단된 파일부터 이어받습니다. 고정된 공식 배포 revision·파일 크기·SHA-256 검증을 통과한 파일만 사용합니다. 같은 모델을 영어·일본어에서 공유하므로 언어마다 다시 받지 않습니다. 준비가 끝나면 인터넷 없이 음성 인식과 번역을 실행할 수 있습니다.

초기 설정은 동영상 음성 / 영어 → 한국어 / 원문 숨김 / 기록 저장 끔입니다. 권한이나 모델 준비만으로 캡처를 시작하지 않으며 사용자가 시작 버튼을 눌러야 합니다.

## 개인정보 보호
- 음성·인식문·번역문을 외부 서비스로 보내는 기능과 클라우드 번역 대체 경로가 없습니다.
- 네트워크 권한은 명시적인 모델 준비에 사용합니다. 다운로드 서버에는 일반적인 접속 정보(IP 등)가 전달될 수 있습니다. 모델 URL은 고정되어 있으며 음성·문장을 URL이나 요청 본문에 넣지 않습니다.
- ML Kit SDK와 해당 SDK 진단 통신 경로를 제거했습니다. Firebase, 광고·결제·오류 수집·피드백 SDK도 사용하지 않습니다.
- 음성·번역문을 Android 로그에 기록하지 않습니다. Android 앱 백업 및 기기 간 전송 백업을 차단합니다.
- 기록 저장을 켠 뒤의 확정 번역만 앱 내부에 저장하며 최근 500개를 보관합니다. 저장을 꺼도 기존 기록은 유지되며 기록 화면에서 별도로 삭제합니다.
- 소스 검사와 라이브러리 구성 검증은 실제 기기의 모든 네트워크 패킷을 관찰한 결과와 다릅니다.

## 자막과 처리 한계
- 음성 구간을 VAD로 구분하고 최대 8초로 제한합니다. 영어·일본어 모두 확정된 구간을 번역합니다. 처리 시간은 구간 수집 시간에 추가됩니다.
- 인식 대기와 번역 대기는 각각 최대 2개이며 현재 처리 중인 작업은 별도입니다. 기기가 처리 속도를 따라가지 못하면 오래된 대기를 생략하고 안내합니다.
- 긴 자막은 첫 줄부터 보여 주고 읽던 위치를 가능한 범위에서 유지합니다. 자막형은 최근 2개, 대화형은 최근 40개를 표시합니다.
- 음성 인식 모델과 번역 모델을 함께 실행하므로 메모리·배터리·발열 부담이 있습니다. 기기의 메모리 여유와 다른 실행 앱에 따라 속도가 달라집니다.
- 보호된 영상, 겹치는 대화, 음악, 짧은 발화, 고유명사에서는 누락·오인식·잘못된 번역이 생길 수 있습니다. 생성형 모델이므로 실제 발화에 없는 내용을 출력할 가능성도 있습니다.
- 공개 샘플 CPU 실행은 Android 실기기의 속도·정확도·배터리를 보장하지 않습니다. 현재 모델이 모든 영상에서 기존 모델보다 우수하다고 주장하지 않습니다.

## 실제 모델 확인 (2026-10-15)
Google FLEURS 일본어 validation의 첫 10개 고유 문장(137.76초·정규화 후 527자)을 같은 8초 분할·0.5초 무음 패딩·Linux CPU 2스레드로 비교했습니다. NFKC 정규화 후 공백·문장부호를 제외했으며, 한자·숫자 표기 차이는 오류로 셌습니다.

| 음성 인식 | 문자 오류율 | 전체 인식 시간 |
| --- | --- | --- |
| 기존 ReazonSpeech k2-v2 int8 | 21.25% (112/527) | 4.04초 |
| Qwen3-ASR 0.6B int8 | 12.52% (66/527) | 46.91초 |

작은 낭독 음성 표본에서 정확도 개선을 확인했지만 처리 시간은 약 11.6배 늘었습니다. 데이터 revision은 `google/fleurs@8d6448449ef85cacf10301f85c215be519e08061`입니다. 대화·음악·소음·Android 성능으로 일반화할 수 없습니다.

실제 Hy-MT2 C++ 실행에서도 일본어 3문장과 영어 1문장의 한국어 번역을 확인했습니다. Linux CPU 2스레드에서 문장당 1.7~2.4초, 최대 프로세스 메모리 약 1.86GiB였습니다. ML Kit과의 정량 비교는 수행하지 않았습니다. 휴대폰에서는 두 모델과 언어 식별기·다른 앱이 메모리를 함께 사용하므로 실기기 확인이 필요합니다.

## 빌드
JDK17, Python3, Android SDK36, NDK28.2.13676358, CMake3.22.1이 필요합니다. 빌드 단계에서는 고정된 sherpa-onnx AAR, Whisper Tiny 언어 식별, Silero VAD, llama.cpp 소스를 준비합니다. 대형 음성·번역 모델을 빌드 서버에서 받거나 APK에 넣지 않습니다.

```bash
python scripts/prepare_language_id.py
python scripts/prepare_speech_support.py
python scripts/prepare_native_translation.py
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows PowerShell에서는 마지막 줄을 다음과 같이 실행합니다.

```powershell
./gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions의 **Private Android APK**도 동일한 준비·검증을 수행합니다. 지속적인 업데이트 설치에는 동일한 앱 ID와 서명이 필요합니다.

원본 MIT 고지는 [LICENSE](LICENSE)에 유지됩니다. 모델과 실행기 출처·고정 버전은 모델 목록 및 준비 스크립트에 기록합니다.

## 이전 버전 변경 기록
아래는 각 버전 배포 당시의 기록입니다. 엔진·다운로드·개인정보 설명은 위의 **현재 엔진과 최초 모델 준비**를 기준으로 합니다.

## 안정화 변경 (1.0.1)
- 인식 시작·캡처·종료를 한 작업이 소유하며 중지는 마지막 발화 처리와 자원 해제가 끝날 때까지 기다립니다.
- 확정 문장은 즉시 번역하고 임시 인식 결과는 300ms 간격으로 묶습니다. 중지 시 확정 번역을 최대 6초 동안 완료하며, 실패나 시간 초과는 안내합니다.
- 기록은 Android 백업 제외 디렉터리에 저장하고, 복구 사본에도 현재 데이터만 보관합니다. 개별 삭제한 문장은 이전 백업에서 복원하지 않습니다.
- 권한 허용만으로 번역을 시작하지 않으며, 시작 대기·실행·종료 중에는 입력 소스와 언어 선택을 잠급니다.
- 기록 화면은 새 기록을 갱신하고 Android 뒤로가기를 처리합니다. 자막 창 위치·크기는 화면에 맞게 보정하며 위치 초기화를 제공합니다.
- 불투명도 범위는 20–100%로 통일하고 자막 버튼은 최소 44dp의 터치 영역을 제공합니다.

ML Kit SDK의 진단 수집 가능성은 유지됩니다. 독립 번역 엔진으로 교체하지 않았으며, 완전 무통신 또는 최초 모델 설치 성공을 보장하지 않습니다. 검증된 별도 번역 모델을 임의로 ML Kit에 넣는 방식은 공식 지원 경로가 아니므로 사용하지 않습니다.


## 모델 다운로드 변경 (1.0.2)
- Wi-Fi 전용 조건을 해제하여 모바일 데이터로도 번역 모델을 준비할 수 있습니다.
- 최초 다운로드가 가능하도록 네트워크 권한을 추가하고, 다운로드 버튼과 실패 안내를 수정했습니다.
- 모델 다운로드는 사용자가 준비 버튼을 누를 때 요청합니다. 음성·문장 처리는 계속 기기에서 실행하며 Google SDK의 진단 수집 안내를 유지합니다.


## 팝업 가독성 변경 (1.0.3)
- 상단에는 이동 영역·일시정지·펼치기 버튼을 표시하고, 자동 따라가기가 멈추면 최신 자막 이동 버튼을 함께 표시합니다. 펼치면 표시 방식, 원문 표시, 최소화 및 종료를 조작할 수 있습니다. 우측 하단의 대각선 아이콘을 드래그하면 크기가 바뀝니다.
- 기본은 확정된 문장만 표시합니다. 인식 중인 문장과 상태 갱신이 읽고 있던 번역을 계속 바꾸지 않습니다. 발화가 끝난 뒤 번역하므로 실시간 미리보기보다 자막이 늦게 나타날 수 있습니다.
- 앱의 자막 설정이나 팝업에서 자막형·대화형을 선택할 수 있습니다. 자막형은 최근 2개 자막, 대화형은 최근 40개 자막을 표시합니다.
- 이전 자막을 읽으면 자동 스크롤이 멈춥니다. 최신 자막 버튼은 최신 문장의 첫 줄을 보여 주며, 긴 문장은 읽는 위치를 유지합니다. 아래 끝까지 직접 스크롤하면 다시 최신 자막을 따라갑니다. 각 문장은 창 너비에 맞춰 줄바꿈하며 원문은 해당 번역과 함께 표시합니다.
- 확정 문장만 표시를 끄면 인식 중인 번역을 미리 볼 수 있습니다. 표시 방식과 조작부 펼침 설정은 다시 실행해도 유지됩니다.
- 대화형 자막은 실행 중 메모리에 보관하며 종료하면 지워집니다. 파일 기록 저장은 기존의 별도 설정을 따릅니다.


## 긴 발화 처리 수정 (1.0.4)
- 자연스러운 발화 종료를 기다리되, 멈춤 없이 길게 말하면 약 6초의 PCM 음성 구간마다 자막을 확정해 번역합니다. 마지막 짧은 구간은 중지할 때 한 번만 처리합니다. 기기 처리 속도에 따라 실제 표시 시간은 달라집니다.
- 번역 대기는 최대 2개이며, 현재 처리 중인 번역은 별도입니다. 처리보다 음성이 빠르면 가장 오래된 대기 자막을 생략하고 최신 구간을 유지합니다. 생략 안내는 자막 창의 상단과 펼친 조작부, 앱 상태에 표시됩니다. 이미 확정된 자막과 저장된 기록은 유지됩니다.
- 음성이 없거나 인식 결과가 비어 있는 구간은 번역 요청을 만들지 않습니다. 비어 있는 확정 결과가 나오면 해당 임시 자막만 정리합니다.
- 긴 발화를 나누는 지점이 문장의 끝과 일치하지 않을 수 있어 문맥에 따른 인식·번역 품질은 달라질 수 있습니다. 연속 음성에 대한 실제 기기 검증은 별도로 필요합니다.


## 일본어 음성 인식 변경 (1.0.5)
- 일본어는 ReazonSpeech k2-v2 int8 + Silero 음성 구간 감지로 인식합니다. 영어는 기존 Vosk를 유지합니다. 일본어 모델 파일은 공식 저자의 revision과 SHA-256으로 고정해 빌드할 때만 준비하며 앱에서 내려받지 않습니다.
- 일본어는 조용한 구간이 1초 이어지면 발화를 확정합니다. 길게 이어지는 음성은 최대 8초로 제한하고 디코더 끝 문맥을 위한 무음 0.5초를 추가합니다. 단어·문장 끝이 강제 경계와 일치하지 않을 수 있으며, 일본어는 인식 중 미리보기 없이 확정 구간을 표시합니다.
- 일본어 인식은 캡처와 분리된 IO 작업에서 실행합니다. 대기는 최대 2개와 진행 중 1개이며, 느린 기기에서는 오래된 대기 음성 구간을 생략하고 안내합니다. 중지는 이 제한된 대기와 현재 native 추론을 마친 뒤 자원을 해제합니다. 중지 시간이 일정하다고 보장하지 않습니다.
- 일본어 문자 사이 토큰 공백을 정리해 동일한 원문을 화면·한국어 번역·선택적 기록에 사용합니다. 영어 단어, 숫자, 전각 문자와 내부 줄바꿈은 보존합니다.
- 한국어 번역 엔진은 기존 ML Kit입니다. 일본어→한국어에서 영어를 중간 언어로 사용하는 품질 한계가 있으며, 이번 버전에서 직접 번역 모델로 교체하지 않았습니다.
- 공개된 일본어 예제 5개(50.51초)의 실제 native CPU 비교에서 기존 Vosk 6초 구간은 문자 오류 23/198, 새 모델과 분할 방식은 8/198을 보였습니다. 작은 공식 예제이며 표기 차이도 오류에 포함됩니다. 휴대폰 속도·실제 영상·한국어 번역의 개선 폭은 검증하지 않았습니다.

일본어 모델 출처: https://huggingface.co/reazon-research/reazonspeech-k2-v2/tree/291488c8151be24d7da4bf7af26e533fad96e407 . 실행기는 기존 sherpa-onnx 1.13.8을 사용합니다. 이 저장소의 `docs/superpowers/specs/2026-10-14-japanese-asr-design.md`와 구현 계획에 처리 상한·종료·오류 검증 범위를 기록했습니다.


## 리뷰 안정화 변경 (1.0.6)
- 일본어를 8초 경계에서 나눈 뒤 남은 짧은 연속 음성을 버리지 않습니다. 독립적으로 발생한 0.25초 미만의 짧은 소리는 기존 감지 필터를 유지합니다.
- 영어와 일본어 모두 일시정지 전후 음성 구간을 분리하고, 정지 중 쌓인 오디오와 전환 중 읽은 오디오가 재개 후 자막에 섞이지 않도록 처리합니다. 준비 중 일시정지 요청도 유지합니다.
- 기록 저장 동의는 번역 요청과 저장 시점을 함께 확인합니다. 저장을 끄면 대기 중인 저장 권한을 무효화하며, 다시 켜도 이전 요청을 뒤늦게 저장하지 않습니다. 이미 저장된 기록은 삭제하지 않습니다.
- 기록 화면에서 긴 원문과 번역을 펼쳐 끝까지 읽을 수 있습니다. 기록 조회·삭제 실패는 목록을 유지하고 오류와 다시 시도 버튼을 표시합니다. 정상 복구 사본이 있으면 복구하지만, 존재하는 파일이 모두 손상되었거나 읽을 수 없는 경우 빈 기록으로 덮지 않습니다.
- 음성 권한을 반복해서 거부해 시스템 요청창이 더 이상 나오지 않는 경우 앱 설정 이동을 안내합니다. 설정에서 돌아온 것만으로 번역을 자동 시작하지 않습니다.
- 화면 회전·접힘에 따른 팝업 크기 보정은 저장한 선호 크기를 덮지 않습니다. 화면 읽기 기능의 사용자 지정 동작으로 팝업을 상하좌우 이동할 수 있습니다.
- Whisper 언어 식별과 영어 Vosk 파일도 고정한 크기·해시로 검증하고, 손상·중단된 모델 준비를 다시 처리합니다.
- 한국어 번역 엔진은 ML Kit이며 일본어→한국어 직접 번역 모델로 교체하지 않았습니다. 음성 원문 누락 수정은 번역 입력을 보완하지만 번역 모델 자체의 문맥·표현 품질을 보장하지 않습니다.


## 사용 흐름 보완 (1.0.7)
- 긴 최신 자막은 첫 줄부터 표시하고, 창 너비·글자 크기·원문 표시·자막형/대화형 전환 후에도 읽던 문장을 기준으로 위치를 복원합니다. 자막형 2개·대화형 40개의 보관 범위에서 유지하며, 읽던 문장이 범위를 벗어나면 남은 가장 오래된 문장부터 표시합니다.
- 시작 영역에 선택 언어와 음성 입력을 표시하고, 아직 필요한 권한과 번역 모델 준비 버튼을 모았습니다. 준비를 마치면 이 안내는 숨깁니다. 번역 모델은 명시적인 준비 버튼으로 Wi-Fi 또는 모바일 데이터를 이용해 내려받습니다.
- 음성 대기·실제 인식/번역 처리·일시정지·종료 중을 구분합니다. 종료 중에는 마지막 음성과 번역 처리를 기다리며 반복 중지·재시작을 막습니다. 평소 팝업 헤더는 44dp를 유지하고, 오류나 무음 안내가 있을 때만 별도 안내를 표시합니다.
- 추천 언어 변경은 중복 탭을 막고, 설정 저장에 성공한 뒤 현재 번역을 종료하면서 앱의 시작 화면을 엽니다. 모델 준비와 권한 확인을 거쳐 사용자가 직접 다시 시작합니다. 권한 창이나 캡처를 자동으로 시작하지 않습니다.
- 기록 화면에서 저장 설정을 바로 변경하고 최근 500개 보관 및 저장 중단·삭제 기준을 확인할 수 있습니다. 설정·검색·기록을 한 목록에서 스크롤해 작은 화면에서도 접근할 수 있습니다.
- 팝업의 펼친 조작부에 표시 방식, 원문 보기/숨김, 최소화, 번역 종료 이름을 붙였습니다. 좁은 창에서는 가로로 스크롤해 모든 버튼에 접근할 수 있습니다. 최신 자막 이동 버튼은 헤더에 배치해 작은 창에서도 본문을 가리지 않습니다.
