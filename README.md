# 실시간 영상 번역 (개인용)

LiveCaptionN의 MIT 라이선스 소스코드를 기반으로 한 **한국어 개인용 오프라인 영상 자막 앱**입니다.

## 주요 기능
- Android 10 이상에서 캡처가 허용된 다른 앱의 재생 음성 인식
- Vosk를 이용한 영어·일본어 음성의 기기 내 인식
- Whisper Tiny + sherpa-onnx의 **독립 음성 언어 식별**: 서로 다른 발화 구간에서 2회 연속 언어가 다르면 자막 위에 영어·일본어 변경을 제안 (자동 변경 없음)
- Google ML Kit을 이용한 한국어 번역 및 드래그 가능한 자막 오버레이
- 번역 모델 상태 확인 및 **사용자가 버튼을 누르면 Wi-Fi·모바일 데이터로 최초 모델 다운로드** (음성/자막 원문 전송 없음)
- 자막 크기, 투명도, 원문 표시, 번역 기록 저장 여부 설정
- 초기 설정: 동영상 음성 / 영어 → 한국어 / 원문 숨김 / 기록 저장 끔

## 개인정보 보호
- ML Kit 번역 모델 다운로드를 위해 `INTERNET`·`ACCESS_NETWORK_STATE` 권한 사용. 앱의 음성·문장 전송 기능은 없음
- Firebase, AdMob, Google Play Billing, Stripe, Cloudflare, 오류 제보, 피드백, 원격 Whisper, LibreTranslate, GitHub 릴리스 자동 확인 제거
- 음성·번역문을 Android 디버그 로그에 기록하지 않도록 수정
- 앱 백업 및 다른 기기로의 데이터 전송 백업 차단
- 기록은 사용자가 명시적으로 저장을 켠 경우에만 앱 내부 파일에 기록

**중요 — 완전 무전송 앱은 아닙니다.** Google ML Kit은 번역 모델을 내려받는 과정 및 사용 진단 목적으로 **기기 정보, 앱 정보, 사용 언어(출발어·도착어), 사용/성능 이벤트** 등을 수집할 수 있습니다. Google 공식 설명: https://developers.google.com/ml-kit/android-data-disclosure . **영상 음성이나 번역할 문장을 앱에서 외부 번역 서버로 전송하는 기능은 제거했습니다.** 번역 자체는 기기에서 처리하지만, 네트워크 권한은 모델 다운로드뿐 아니라 Google SDK의 진단 통신에도 사용될 수 있으며, 모델 준비 버튼 이전의 SDK 초기화 통신까지 차단한다고 보장할 수는 없습니다. 제3자 통신 자체가 허용되지 않는 환경에서는 이 버전을 사용하지 말고 별도 모델을 번들로 포함한 독립 실행형 번역 엔진으로 교체해야 합니다.

## 빌드
JDK 17, Android SDK 및 Python 3이 필요합니다. **Vosk 음성 모델(영어 약 40MB, 일본어 약 48MB), sherpa-onnx Android AAR(v1.13.8), Whisper Tiny int8 언어 식별 모델**은 개발 환경 또는 GitHub Actions 빌드 머신에서만 공식 서버로부터 다운로드해 APK에 포함합니다. Android 앱에는 이러한 음성 모델의 다운로드 기능이 없습니다. 단, **ML Kit 번역 모델(언어당 약 30MB)은 별도**로, 사용자가 앱의 번역 모델 준비 버튼을 눌러 설치해야 합니다. Wi-Fi와 모바일 데이터 모두 사용할 수 있으며, 모바일 데이터 사용 시 요금이 발생할 수 있습니다.

```bash
python scripts/prepare_vosk_models.py
python scripts/prepare_language_id.py
./gradlew testDebugUnitTest assembleDebug
```

Windows PowerShell:
```powershell
python scripts/prepare_vosk_models.py
python scripts/prepare_language_id.py
./gradlew.bat testDebugUnitTest assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

GitHub Actions의 **Private Android APK** 워크플로도 같은 과정을 실행해 APK 아티팩트를 생성합니다. Debug APK는 개발용 서명으로 만들어지므로, 지속적인 업데이트 배포를 위해서는 별도 서명 체계가 필요합니다.

## 제한 사항
- 보호된 콘텐츠나 오디오 캡처를 차단한 앱에서는 시스템 음성을 인식할 수 없습니다.
- 현재 APK에 포함되는 음성 인식 모델은 영어·일본어입니다. 언어 자동 감지는 지원하지 않습니다.
- Vosk small 모델은 고유명사, 빠른 대화, 잡음에 따른 인식 오류가 발생할 수 있습니다.
- 최초 ML Kit 번역 모델 준비 전에는 번역 시작 버튼이 비활성화됩니다. 버튼을 누르면 Wi-Fi 또는 모바일 데이터로 모델 준비를 요청하며 90초 후 시간 초과를 안내합니다. 네트워크 연결, 저장 공간 및 기기 설정에 따라 다운로드가 실패할 수 있습니다. 모델 준비 후에는 음성 인식과 번역을 오프라인으로 실행할 수 있습니다. 실제 모바일 데이터 다운로드 성공은 실기기에서 별도 확인해야 합니다.
- 언어 식별은 Vosk의 문장부호 기준이 아니라 **음성 인식으로 확정된 독립 발화 구간 2개**를 기준으로 합니다. 소음·혼합 언어·짧은 발화에서는 오탐 또는 미탐이 가능하며, 영어·일본어에 대해서만 전환을 추천합니다.
- 자동 언어 변경은 하지 않습니다. 오버레이에서 변경을 승인하면 현재 캡처가 종료되고, 사용자가 앱에서 다시 시작해야 합니다.
- APK 안에 소형 ASR 2개 + Whisper Tiny + native 라이브러리가 들어가 설치 파일 크기와 메모리 사용량이 증가합니다.

원본 저작권 및 MIT 라이선스 고지는 [LICENSE](LICENSE)에 유지됩니다.


## 안정화 변경 (1.0.1)
- 인식 시작·캡처·종료를 한 작업이 소유하며 중지는 마지막 발화 처리와 자원 해제가 끝날 때까지 기다립니다.
- 확정 문장은 즉시 번역하고 임시 인식 결과는 300ms 간격으로 묶습니다. 중지 시 확정 번역을 최대 6초 동안 완료하며, 실패나 시간 초과는 안내합니다.
- 기록은 Android 백업 제외 디렉터리에 저장하고, 복구 사본에도 현재 데이터만 보관합니다. 개별 삭제한 문장은 이전 백업에서 복원하지 않습니다.
- 권한 허용만으로 번역을 시작하지 않으며, 시작 대기·실행·종료 중에는 입력 소스와 언어 선택을 잠급니다.
- 기록 화면은 새 기록을 갱신하고 Android 뒤로가기를 처리합니다. 자막 창 위치·크기는 화면에 맞게 보정하며 위치 초기화를 제공합니다.
- 불투명도 범위는 20–100%로 통일하고 자막 버튼은 최소 44dp의 터치 영역을 제공합니다.

ML Kit SDK의 진단 수집 가능성은 유지됩니다. 독립 번역 엔진으로 교체하지 않았으며, 완전 무통신 또는 최초 모델 설치 성공을 보장하지 않습니다. 검증된 별도 번역 모델을 임의로 ML Kit에 넣는 방식은 공식 지원 경로가 아니므로 사용하지 않습니다.


## 모델 다운로드 변경 (1.0.2)
- Wi-Fi 전용 조건을 해제하여 모바일 데이터로도 번역 모델을 준비할 수 있습니다.
- 최초 다운로드가 가능하도록 네트워크 권한을 추가하고, 다운로드 버튼과 실패 안내를 수정했습니다.
- 모델 다운로드는 사용자가 준비 버튼을 누를 때 요청합니다. 음성·문장 처리는 계속 기기에서 실행하며 Google SDK의 진단 수집 안내를 유지합니다.


## 팝업 가독성 변경 (1.0.3)
- 상단은 이동 영역·일시정지·펼치기 버튼만 표시합니다. 펼치면 표시 방식, 원문 표시, 최소화 및 종료를 조작할 수 있습니다. 우측 하단의 대각선 아이콘을 드래그하면 크기가 바뀝니다.
- 기본은 확정된 문장만 표시합니다. 인식 중인 문장과 상태 갱신이 읽고 있던 번역을 계속 바꾸지 않습니다. 발화가 끝난 뒤 번역하므로 실시간 미리보기보다 자막이 늦게 나타날 수 있습니다.
- 앱의 자막 설정이나 팝업에서 자막형·대화형을 선택할 수 있습니다. 자막형은 최근 2개 자막, 대화형은 최근 40개 자막을 표시합니다.
- 대화형에서 위로 스크롤해 이전 자막을 읽으면 자동 스크롤이 멈춥니다. 최신 자막 버튼으로 다시 아래를 따라갑니다. 각 문장은 창 너비에 맞춰 줄바꿈하며 원문은 해당 번역과 함께 표시합니다.
- 확정 문장만 표시를 끄면 인식 중인 번역을 미리 볼 수 있습니다. 표시 방식과 조작부 펼침 설정은 다시 실행해도 유지됩니다.
- 대화형 자막은 실행 중 메모리에 보관하며 종료하면 지워집니다. 파일 기록 저장은 기존의 별도 설정을 따릅니다.


## 긴 발화 처리 수정 (1.0.4)
- 자연스러운 발화 종료를 기다리되, 멈춤 없이 길게 말하면 약 6초의 PCM 음성 구간마다 자막을 확정해 번역합니다. 마지막 짧은 구간은 중지할 때 한 번만 처리합니다. 기기 처리 속도에 따라 실제 표시 시간은 달라집니다.
- 번역 대기는 최대 2개이며, 현재 처리 중인 번역은 별도입니다. 처리보다 음성이 빠르면 가장 오래된 대기 자막을 생략하고 최신 구간을 유지합니다. 생략 안내는 자막 창의 상단과 펼친 조작부, 앱 상태에 표시됩니다. 이미 확정된 자막과 저장된 기록은 유지됩니다.
- 음성이 없거나 인식 결과가 비어 있는 구간은 번역 요청을 만들지 않습니다. 비어 있는 확정 결과가 나오면 해당 임시 자막만 정리합니다.
- 긴 발화를 나누는 지점이 문장의 끝과 일치하지 않을 수 있어 문맥에 따른 인식·번역 품질은 달라질 수 있습니다. 연속 음성에 대한 실제 기기 검증은 별도로 필요합니다.
